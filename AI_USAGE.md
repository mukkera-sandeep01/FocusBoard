# AI Usage Disclosure

AI assistance was used to create the initial project structure, React components, CSS styling, task interactions, localStorage hook, README and this disclosure.

## Tools used

- ChatGPT

## Representative prompts

1. Create a beginner-friendly React + Vite task dashboard based on the FocusBoard trainee assignment.
2. Implement task creation, editing, deletion, status changes, search and combined filters.
3. Add derived dashboard statistics and localStorage persistence using React hooks.
4. Make the dashboard responsive for desktop, tablet and mobile screens.
5. Create a three-slide Focus Notes carousel with working navigation controls.

## AI-assisted areas

The initial code for the app layout, reusable components, styling, task data, localStorage persistence, and documentation was AI-assisted.

## Verification and changes required

The project owner must run the application, test all interactions, compare the result with the live Figma reference, correct any visual or functional issues, and be able to explain the implementation. In particular, verify the exact Focus Notes slide content against Figma before submission.

## Understanding checklist

Before submitting, make sure you can explain:
- What React components are and why the UI is split into components.
- How `useState` updates the UI.
- How the `useLocalStorage` hook saves and restores tasks.
- How search and filters combine.
- How statistics are calculated from the task array.
- How the form validates required fields.
